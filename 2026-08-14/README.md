# 2026-08-14 AI 论文推荐

1. **VAKRA: Evaluating Multi-Hop Reasoning Across APIs and Retrieval Under Tool-Use Policies**
   - 链接：[01-vakra.md](./01-vakra.md)
   - Spotlight：首个把 API 调用、检索推理和自然语言策略约束放在统一 benchmark 的工具型 Agent 任务中，结果显示真实最困难点集中在语言层面的跨源推理与歧义消解。
   - 推荐顺序：★★★★★

2. **Learning When to Trust via Selective Context Preference Optimization**
   - 链接：[02-scope.md](./02-scope.md)
   - Spotlight：提出“Selective Context”视角，把“抵抗错误上下文”和“信任正确上下文”同时建模，并在公开模型上显著降低误导翻转率 SC2W。
   - 推荐顺序：★★★★★

3. **HandEdit: A Unified Benchmark for Egocentric Human-to-Robot Dexterous Hand Image Editing**
   - 链接：[03-handedit.md](./03-handedit.md)
   - Spotlight：给出 200M 人类手部 egocentric 编辑实例与统一评测协议，在手部机器人映射任务中明确搭起大规模具身图像编辑数据+Benchmark 基线。
   - 推荐顺序：★★★★☆

4. **StateFlow: Building, Evolving, and Accessing 3D World States for Previsualization**
   - 链接：[04-stateflow.md](./04-stateflow.md)
   - Spotlight：用“可持久 3D 世界状态”替代一次性 2D/3D 生成，支持迭代编辑、摄影机规划与场景重构，适合关注创意 AI 与生成系统可控性问题。
   - 推荐顺序：★★★★☆

5. **How to Spend Your Oracle Budget: Practical Guidance for Protein Structure Prediction Models**
   - 链接：[05-oracle-budget.md](./05-oracle-budget.md)
   - Spotlight：首次给出 Oracle budget 不同预算条件下的实践性选择建议：低预算更偏向 O3，高预算更适合 FK-steering/DPO，适合部署决策参考。
   - 推荐顺序：★★★★☆
