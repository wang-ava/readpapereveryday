**Spotlight：** Agora 把 Agent 的研究结果、失败与复现记录变成可追溯的 Git 提交，让后续研究能够接续已有证据。近 12 天的运行证明了协作流程可以持续运转，但尚未证明共享记忆能提高单位算力的发现效率。

# Agora: Git as Shared Memory for Collective AutoResearch

## 论文信息

- 作者：Yifan Zhang、Yunheng Zou、Shaokun Zhang、Jian Hu、Hao Zhang、Binfeng Xu、Jan Kautz、Yi Dong。
- 机构：NVIDIA。
- 发布日期：2026-09-16；阅读版本：arXiv v1，核对摘要及正文第 3–4 节、附录 C。
- 主题标签：#AI论文 #Agent #自动科研 #共享记忆 #可复现研究
- [论文](https://arxiv.org/abs/2609.18094v1) · [PDF](https://arxiv.org/pdf/2609.18094v1) · [正文](https://arxiv.org/html/2609.18094v1)

## 核心问题

多个科研 Agent 如果只保留各自的聊天历史，就容易重复探索、遗失失败经验。怎样让研究主张、代码版本和验证结果跨会话积累，并让后来者看到尚未充分探索的方向？

## 方法概要

每项贡献保存为只追加的 Git DAG 节点，父边表示研究依赖；SQLite 提供可重建的查询索引。系统区分结果、洞见、假设和复现，利用其他账户的后续工作与验证作为证据信号，同时展示热门与冷门分支。多样性启发式帮助分配探索注意力，但其评分不等于科学真伪。

## 主要贡献

把可执行工件与研究主张绑定；保留失败和复现的来源链；给出长期 Agent 运行案例与可审计轨迹，并明确提出后续匹配对照设计。[来源：正文第 3 节](https://arxiv.org/html/2609.18094v1#S3)

## 关键实验或结果

13 个 worker 在近 12 天中参与权重迁移任务：从 141 个 donor 模型为约 119.6M 参数的异构目标模型构造初始化，不使用训练语料或目标模型梯度更新。系统记录 1,703 项贡献，评估值从随机初始化的 3.3923 降至约 1.899 bits per byte，越低越好。

关键限定：评估始终使用同一组 200 条 FineWeb-Edu 文本。前 18 个带分数结果已贡献约 98% 的总降幅；165 条复现记录覆盖 95 个不同目标，并非 165 个独立研究任务。中途人类部署了多样性视图；“无人中央派工”不能理解成“完全无人干预”。[来源：第 4 节、表 4](https://arxiv.org/html/2609.18094v1#S4)

## 适合关注的原因

适合搭建长期科研助手或跨会话实验系统的人阅读：最可借鉴的是将失败、依赖关系、复现状态作为一等记录，而不仅保存最终最佳分数。

## 局限性或待验证点

作者明确缺少等预算独立搜索对照，因此不能归因出共享 DAG 的效率收益。反复针对同一开发评估器优化会带来选择偏差；最后微小改进低于跨硬件差异。账户之间的复现说明工件可运行，不等同于外部实验室独立验证，也不能推导真实科学发现能力。

## 对后续研究/应用的启发

建议将“可追溯共享状态”“多样性提示”“额外计算量”分开消融，使用隐藏测试集并记录总 token、GPU 时间和失败成本。Ava 的论文知识库也可借鉴主张—证据—后续验证之间的显式链接；这是应用建议，并非本文实验证实的效果。

## 中文快速总结

> 把 Agent 的研究过程存成可复现的证据图很有价值，但可协作不等于已证明更高效。

## 标准化研究框架

**Research question：** 持久且可审计的共享状态能否支持异步 Agent 累积研究进展？

**Literature：** 连接 AutoResearch、科研 Agent、多 Agent 协作、黑板系统、可复现工件与质量多样性搜索；相关工作见正文第 2 节。

**Theory：** 等价于系统设计依据：公共记忆降低信息遗失，来源链支持核验，多样性视图缓解探索集中；并非已证明的效率定理。

**Hypotheses：** 等价于待验证的工程预期：共享状态有助于复用和探索；本研究没有完成等预算因果检验，不能视为假设已被验证。

**Method：** Git DAG 系统构建、长期运行案例、贡献轨迹审计与复现记录分析。

**Data and Analysis：** 分析 1,703 项贡献及其关系；目标性能由固定 200 文本评估器给出，同时考察来源链与探索集中度。

**Findings：** 性能由约 3.39 降到 1.90 bpb，跨账户接续与复现存在，但重复搜索及集中于单一路线也存在。

**Conclusion：** 展示可持续、可追溯的协作机制；效率优越性与跨任务泛化仍需受控实验。
