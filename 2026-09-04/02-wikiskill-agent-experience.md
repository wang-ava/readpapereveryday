## 核心问题
当前 agent 技能进化方法往往把优化历史分散在不同轨迹中，缺少可复用、可迁移的持久化知识结构，如何让经验真正“沉淀”为可演进的能力资产？

## 方法概要
- 将 agent 执行经验、知识积累与可执行技能进行分层建模。
- 引入持续更新的 wiki 结构，用来持久存储跨轮次优化中提炼出的经验。
- 在技能更新周期中持续将新经验合并进 wiki，再让后续技能学习复用该知识。
- 通过跨模型/跨家族迁移实验检验技能可迁移性。

## 主要贡献
1. 提出 WikiSkill 的“经验-知识-技能”三位一体结构，形成持续进化流程。
2. 证明 persistent wiki 的持续积累是技能进化有效性的关键成分。
3. 显示 evolved skills 在跨模型与跨家族场景下仍可产生增益，并观察到“跨模型可借鉴技能”现象。

## 关键实验或结果
- 在多数据集与多模型评测下，WikiSkill 在多数场景优于 baseline 和现有 skill-evolution 方法。
- 结果显示引入技能后，小模型可在部分任务上超过无技能的大模型。
- 跨模型迁移测试表明，第三方进化技能有时能显著优于自进化技能，说明知识表征更具泛化潜力。
- 消融实验支持“持久知识汇聚”是性能改进的必要条件之一。

## 适合关注的原因
- 对“agent 开发平台、agent 团队协作记忆、长期运行服务”具有实用价值。
- 能帮助团队理解：不只是参数更新，经验的结构化累积同样决定长期学习效率。

## 局限性或待验证点
- 论文当前版本摘要缺少开源实现与工程指标（如成本、吞吐、上下文增长速度），工程落地需要更多细节。
- 在非同源任务体系中的持续收益边界不够明确，尤其是任务分布发生突变时的退化机制。
- 若 wiki 噪声扩散，是否有稳健的知识遗忘/重置机制尚待补充。

## 对后续研究/应用的启发
- 可将“技能 wiki”思路用于内部智能体编排系统，形成经验复用和治理策略。
- 对 AI 开发生态可借鉴的关键问题是：如何定义经验可信度，防止“伪 skill”污染知识库。
- 适合作为 agent 生命周期管理（更新、回滚、继承）的基础模块继续研究。

## 一句话中文速览总结
WikiSkill 通过把 agent 经验结构化持久化，给出了从短期调参到长期能力累积的可执行演化路径。

## 标准化研究框架
- **Research question：** 能否将 agent 经验从一次性执行日志升级为可复用知识资产，从而显著提升技能进化效果与迁移能力？
- **Literature：** 归入 agent skill acquisition 与持续学习方向，可与最近的技能蒸馏、记忆增强 RL、工具学习方法对齐。
- **Theory：** 假设“持续可检索的知识表征”可降低技能学习的样本与探索成本，并提高跨模型迁移稳定性。
- **Hypotheses：** 分层拆分执行经验、知识和技能；如果知识在 wiki 中持续累积，则可带来超过基线的泛化改进。
- **Method：** 构建三层表示与更新机制，进行跨模型/跨家族消融，比较有无持久知识的多任务成绩。
- **Data and Analysis：** 使用多任务/多模型实验对比（含是否使用技能库、是否自进化 vs 外部进化）并做 ablation。
- **Findings：** 实验表明持久化知识显著提升 skill evolution 的有效性，跨模型迁移具有一定可行性，知识积累对性能贡献明显。
- **Conclusion：** 对非社会科学研究，本研究可转化为“是否建立可审计的经验记忆仓库”这一工程问题；结论支持在 agent 系统中引入持久化经验层。
