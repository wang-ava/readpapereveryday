## 推荐顺序与 spotlight

1. [CritICL: Inference-Time Weak-to-Strong Generalization from Small Language Model Failure Modes](2026-08-31/01-criticl.md)
   - Spotlight：将小模型失败模式显式转化为推理约束，在 inference-time 以极低额外成本提升 LLM 的鲁棒性与输出质量。

2. [Physical Agentic AI: An Architecture for Orchestrating a Robot Crew with LLMs](2026-08-31/02-physical-agentic-ai.md)
   - Spotlight：把 LLM 规划与机器人执行显式解耦，通过分层执行网关提高任务完成率和物理安全。

3. [Retrieval Heads Meet Vision: Uncovering How VLMs Locate and Extract Visual Information](2026-08-31/03-retrieval-heads-vlm.md)
   - Spotlight：提出少量关键注意力头驱动 VLM grounding 机制，给可解释性与鲁棒性优化带来新抓手。

4. [CLAP: Cross-Embodiment Video World Models are Zero-Shot Physical Simulators](2026-08-31/04-clap.md)
   - Spotlight：尝试学习跨形态共享的物理先验，让视频世界模型在零样本条件下兼容不同机器人形态。

5. [Learning a Continuous Sepsis Severity Score Without Hour-by-Hour Supervision: A Two-Site Retrospective Study](2026-08-31/05-sepsis-severity-score.md)
   - Spotlight：用无小时级监督的排序学习框架构建脓毒症连续风险评分，并在两站点评估其可迁移性。
