# OR-Agent: Bridging Evolutionary Search and Structured Research for Automated Heuristic Design

**Spotlight：** OR-Agent 不只做“让 LLM 改改参数”，而是把启发式算法设计抽象为可反思的研究流程，尝试在长期搜索中保持策略性而不是短视突变。

## 核心问题
LLM 在优化问题中的自动化启发式设计通常缺乏长期策略，搜索会“试错很多次但难以归纳失败经验”。如何让 agent 像研究流程一样进行结构化反思并持续改进？

## 方法概要
- 构建 tree-based 工作流，将候选启发式的生成、执行、失败和回溯显式建模。
- 引入多层反思机制：
  - 短期反思（verbal gradient）用于局部修正
  - 长期反思（verbal momentum）用于累计方向性经验
  - 记忆压缩（semantic weight decay）用于避免历史噪声污染。
- 在搜索过程里统一“生成—验证—反思—压缩—再生成”。

## 主要贡献
- 将进化搜索与“结构化研究代理”思想结合，形成可追踪的自动启发式设计范式。
- 提供可解释的搜索控制信号（短期/长期反思），降低随机突变带来的效率损失。
- 在 TSP、CVRP、装箱等经典组合优化问题上展示明显优势。

## 关键实验或结果
- 在经典组合优化与仿真协同驾驶场景中，OR-Agent 相比强基线展现更好的优化效果。
- 通过反思记忆策略，搜索路径更聚焦，减少重复失败试验。

## 适合关注的原因
- 这是把“Agent 写代码/调参”升级为“Agent 做科学探索”的可落地模板。
- 对希望自动化复杂算法搜索（调参与结构选择）的人尤其有参考价值。

## 局限性或待验证点
- 公开实验主要围绕传统优化类问题，跨学科真实工程任务验证仍有限。
- 反思机制的超参数较多，迁移到新任务时调参成本可能较高。
- 当前评测尚未完全覆盖对抗性任务/极长时序问题。

## 对后续研究/应用的启发
后续可将该框架迁移到超参数搜索、策略搜索、数据增广策略生成等场景：用“树结构搜索+反思记忆”替代黑箱进化。

## 标准化研究框架
- **Research question：** 多智能体式反思机制能否提升 LLM 驱动的启发式算法搜索效率与解的质量？
- **Literature：** 现有工作常见于 LLM + 进化/变异循环，但缺乏长期记忆和策略回溯；该文在机制层面补齐了“研究式循环”。
- **Theory：** 搜索失败可被显式建模并转为反思信号，树结构有助于保留分支上下文，避免重复探索。
- **Hypotheses：** H1：结构化搜索树能提升关键状态覆盖；H2：短期+长期反思可减少无效试验；H3：记忆压缩可提高跨轮次泛化。
- **Method：** 以经典优化问题为测试床，比较传统进化基线与 OR-Agent 在相同预算下的收敛速度、最优性与稳定性。
- **Data and Analysis：** 实验集含 TSP、CVRP、装箱、协同驾驶仿真；分析指标包括最终目标值、收敛轮数、失败样本复用率。
- **Findings：** 报道显示该方法在多任务上优于强基线，且反思机制对搜索效率有正向作用。
- **Conclusion：** 结构化反思策略是将 Agent 从“自动执行者”走向“自动研究者”的重要一步。
