## 核心问题
当前Transformer在超长序列/超高分辨率场景里要么显存爆炸，要么上下文信息严重丢失。如何在保持可恢复细粒度信息的前提下，同时扩展上下文长度和训练可行性？

## 方法概要
- 建立双流设计：局部流维持细粒度特征，另一个流仅保留代理状态（proxy）完成全局交互。
- 每层先将局部表征压缩为 proxy，再在 proxy 空间执行全局注意力。
- 压缩后的上下文通过解压回注入局部流，避免单次压缩带来的不可逆信息损失。
- 引入分层压缩/解压、动态压缩率、非对称 embedding，以及 proxy-only KV cache 推理。

## 主要贡献
1. 提出可泛化到超长语言建模与图像生成场景的双流 proxy 架构。
2. 在保持训练可扩展性的同时显著延伸可处理 token 上限。
3. 用“低秩近似式交互+局部细粒度回注”减轻传统单向压缩的信息损失。

## 关键实验或结果
- 在 16GB GPU、batch=1 下，传统模型约能处理 20K tokens。
- ProxyFormer（压缩率 64）可把可训练长度扩展到约 0.7M。
- 64K window 下的模型在 1,048,576 token 的多针检索任务上保留 92%~95% 检索准确率。
- 8K window 外推到 256K 时仍保持超过 94% 的准确率。
- 预实验显示方法对像素空间与潜变量空间流匹配均可行。

## 标准化研究框架
**Research question：** 本文不是统计假设检验，而是工程科学问题：如何在不牺牲细粒度信息保真度的情况下显著延展 Transformer 的有效上下文能力与输出分辨率？

**Literature：** 相关工作主要在低秩近似、序列压缩、线性注意力与长上下文学习上各自优化，ProxyFormer 的等价点是将“全局语义交流”和“局部细节保持”分离。

**Theory：** 在本论文中，理论框架是双通道近似计算：局部通道承担局部重建信息，proxy 通道承担全局语义整合。

**Hypotheses：**
1. 双流分离可在不同比例压缩下仍保持关键任务可检索信息。
2. 压缩率可动态调节时，对不同任务长度更鲁棒。
3. proxy-only KV 推理可减少推理成本并抑制显存溢出。

**Method：** 构建 4 个核心模块（局部编码、proxy 压缩/解压、动态比例控制、proxy-only 推理），并在 token 长度与检索任务上测量退化。

**Data and Analysis：** 使用长序列检索任务和多 token 长度条件进行对照；评估指标以可处理长度、检索准确率和资源使用为主。

**Findings：** 在给定算力限制下，ProxyFormer 在更长上下文下保留了较高检索准确率，且未出现传统压缩方法常见的极端信息断层。

**Conclusion：** 双流架构为“超长上下文可扩展性”提供了可复用模板，并在推理成本受限时具有直接工程价值。
