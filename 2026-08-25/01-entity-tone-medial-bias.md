# From Entity Mentions to Tone: An LLM-Based Pipeline for Media Bias Analysis

该文提出了一个面向新闻文本的可复用 pipeline，核心不是再做“单点分类”式偏见判断，而是把实体、情绪与事件建模成可比较的偏向信号。它对新闻素材链路中的可解释偏见分析尤其友好，可直接用于多源舆情监测的“可视化叙事比较”。

该方法的关键价值在于：在低资源语言环境下，也能通过统一 prompts 与标注规则，把语料处理成可复用的 bias 分析表征，再做跨媒体源对照。

## 核心问题
当前媒体偏见研究常受限于手工规则与单点指标，面对多语言低资源场景更缺少可扩展、可比较的流程。论文核心问题是：能否用 LLM pipeline 从同一篇新闻中统一提取人物/事件/语气证据，并支持跨媒体源的偏见与框架差异对比？

## 方法概要
- 先对新闻语料聚类到事件和主题层。
- 用 LLM 对文本进行命名实体和情绪标注，生成实体层与事件层注释。
- 构建源级（source-level）、人物级（person-level）与事件级（event-level）比较指标。
- 对两套提示词策略做对比实验：
  - 更严格情绪校验：一致性更高但覆盖率下降、耗时上升；
  - 较简单 prompt：兼顾成本与覆盖，作为主实验策略。

## 主要贡献
1. 提出一个端到端的媒体偏见分析 pipeline，避免将偏见分析局限于单次分类任务。
2. 把人物、来源与事件三层证据串联为可复用输出表征，便于后续可视化与政策分析。
3. 在低资源语言（阿尔巴尼亚语）中验证了该框架可操作性。

## 关键实验或结果
- 数据：GDELT 中的 8,358 条阿尔巴尼亚新闻。
- 与 GDELT 自动注释对比，情绪与实体提取中等一致性。
- 严格 prompt 改善了一致性，却明显增加执行成本并降低覆盖率。
- 简化 prompt 在时间效率和可覆盖性上更适合大规模分析，成为主模型配置。

## 适合关注的原因
该论文把 LLM 的生成与结构化输出结合在现实可用的偏见分析流程中，不是只追求 benchmark 分数，而是贴近实际媒体监管和舆情研究中的可解释需求。

## 对后续研究/应用的启发
- 可作为新闻监测系统中的 bias dashboard 前置模块，连接抓取、注释、对比三层管线。
- 后续可与地理、政治光谱标签联合，形成多维偏见谱分析。
- 有望扩展为社会议题框架识别（framing）或虚假信息传播路径分析的基础设施。

## 标准化研究框架
**Research question：** 本文不是纯统计检验型研究，更接近“任务流程有效性”问题：给定固定新闻语料，LLM pipeline 是否能稳定产出可比较的实体-情绪-事件证据来支撑媒体偏见分析。

**Literature：** 相关研究以偏见分类、情绪分析和偏见词典方法为主；本论文在既有工作上加入了事件聚类与多层指标联动，尝试把单任务模型推向可运维流程。

**Theory：** 在本文中对应的是“信息抽取 + 聚合推理”框架：文本先通过实体与情绪抽取形成结构化表示，再通过跨源归约形成偏见度量。

**Hypotheses：** 1）统一 pipeline 能在多个比较层面提升可解释性；2）更严格的提示词规则可提升精确性但会带来覆盖率下降；3）在大规模处理下需要在精度与成本间取平衡。

**Method：** 采用事件/主题分组→实体+情绪标注→源级与实体级聚合→不同提示词策略下的对比评估，并与 GDELT 自动注释结果对照。

**Data and Analysis：** 数据规模为 8,358 条阿尔巴尼亚新闻；比较样本包括与 GDELT 注释的一致性、两类提示词策略下的覆盖率/一致性/耗时、源级与事件级指标变化。

**Findings：** 简单提示词在可扩展性上更优，严格提示词在标注一致性上有优势但会牺牲效率和覆盖范围；框架展示了低资源场景可行的 bias 分层分析路径。

**Conclusion：** 本文为媒体偏见研究提供了“可计算化分析流水线”视角，而非单点判别模型；若补齐公开实现和多语言验证，可成为新闻治理与社会分析中的可部署基础模块。
