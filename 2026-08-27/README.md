# 2026-08-27 AI 论文分享

## 当日推荐列表（按优先顺序）

1. **Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses**
   - Spotlight：把 LLM agent 长时任务中的历史负担转为可进化记忆系统，显著提升长时成功率。
   - 链接：`https://arxiv.org/abs/2608.24876`
   - 文件：[01-recuris.md](01-recuris.md)

2. **SPADE: Self-Play in Adaptive Synthetic Executable Environments**
   - Spotlight：把环境生成器放入 agent 学习闭环，让任务分布随模型能力动态“拉满”，在 30B 模型上平均提升 +5.3。
   - 链接：`https://arxiv.org/abs/2608.19197`
   - 文件：[02-spade.md](02-spade.md)

3. **Reading Is Not Using: Retrieval, Judgment, and the Design of AI Financial Research Workflows**
   - Spotlight：提醒我们“检索到 ≠ 用得到”，将关注点从检索指标转到决策流程是否真正吸收关键信息。
   - 链接：`https://arxiv.org/abs/2608.24842`
   - 文件：[03-reading-not-using.md](03-reading-not-using.md)

4. **Do Robotic World Models Really Follow Actions? Diagnosing and Aligning Action-Conditioned Generation for Policy Learning**
   - Spotlight：诊断并修复 world model 对 off-expert 动作响应不足问题，强调动作条件一致性是策略学习前提。
   - 链接：`https://arxiv.org/abs/2608.24885`
   - 文件：[04-robotic-world-models-follow-actions.md](04-robotic-world-models-follow-actions.md)

5. **WithEveryone: Unified Planning and Identity Grounding for Group Image Generation**
   - Spotlight：通过身份寻址与布局规划联合建模，提升多人图像生成的身份保持与重复率控制能力。
   - 链接：`https://arxiv.org/abs/2608.20336`
   - 文件：[05-with-everyone.md](05-with-everyone.md)
