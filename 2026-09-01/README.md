# 2026-09-01 AI 论文推荐

本期按 `Asia/Shanghai` 时间筛选最近更新论文（重点在 7–14 天窗口），覆盖 LLM、Agent、CV、具身智能、AI4S，并输出 5 篇可直接在 Obsidian 阅读的中文笔记。

## 推荐顺序与 spotlight

1. [Understanding the Energy Scaling of Large Language Model Inference Across Context Lengths and Attention Architectures](2026-09-01/01-understanding-energy-scaling-llm-inference.md)
   - Spotlight：论文系统化给出不同 attention 架构在 decode 阶段的能耗扩展规律，为生产部署的成本与延迟决策提供直接依据。

2. [Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses](2026-09-01/02-recuris-long-horizon-agent-harnesses.md)
   - Spotlight：Recuris 用递归记忆演化机制将长链执行中的失败结构化归因并持续修正，显著增强 long-horizon agent 成功率。

3. [LeFlow: Generative Latent Flow Planning for World Models](2026-09-01/03-leflow-generative-latent-flow-planning.md)
   - Spotlight：将世界模型规划转为 latent space 中可复用的轨迹生成，减少 replanning 中反复优化成本。

4. [Do Robotic World Models Really Follow Actions? Diagnosing and Aligning Action-Conditioned Generation for Policy Learning](2026-09-01/04-do-robotic-world-models-follow-actions.md)
   - Spotlight：对 off-expert action 情况下 world model 的遵循性进行量化诊断，并通过对齐策略提升策略学习可靠性。

5. [Rare Diseases, Common Dilemmas: LLMs Prioritize Equal Resource Distribution over Patient Benefit in Decision-Making](2026-09-01/05-rare-diseases-llm-resource-prioritization.md)
   - Spotlight：建立稀有病决策基准后发现 LLM 倾向“公平分配”而忽略严重度差异，警示医疗 AI 的价值对齐风险。
