# 2026-09-02 AI 论文推荐

本期按 `Asia/Shanghai` 日期（覆盖 2026-08-25 到 2026-08-31，优先选择近期论文）生成 5 篇中文 Obsidian 笔记，主题覆盖 LLM、Agent、CV、具身智能、AI4S。

## 推荐顺序与 spotlight

1. [Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses](./01-recuris-long-horizon-agent-harnesses.md)
   - Spotlight：长程任务中提出递归记忆演化闭环，显著降低任务失败传播，显著提升 4 大 benchmark 上的成功率。

2. [Ladders in Chaos: When, How, (and Perhaps Why) Does Test-Time Scaling Improve LLM Machine Translation](./02-ladders-in-chaos-test-time-scaling.md)
   - Spotlight：系统对比顺序式与并行式 test-time scaling 在机器翻译中的收益与衰减机制，为 LLM 推理成本调优提供实用判据。

3. [LeFlow: Generative Latent Flow Planning for World Models](./03-leflow-latent-flow-planning.md)
   - Spotlight：将像素世界模型规划从反复在线优化转向潜在轨迹先验生成，显著减少规划时延并保持成功率。

4. [Do Robotic World Models Really Follow Actions? Diagnosing and Aligning Action-Conditioned Generation for Policy Learning](./04-robotic-world-model-action-following.md)
   - Spotlight：诊断并对齐世界模型动作遵循能力，提醒我们评估不应只看专家动作数据，强调策略学习可执行性。

5. [Cross-Regional Grapevine Cold Hardiness Prediction via Learned Multimodal Latent Representations](./05-cross-regional-cold-hardiness-prediction.md)
   - Spotlight：通过可迁移多模态潜表示解决跨区域冷硬度预测泛化问题，兼顾零样本/少样本场景。
