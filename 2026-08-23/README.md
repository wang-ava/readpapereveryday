## 推荐顺序

1. [01-conceptguard-benchmark.md](01-conceptguard-benchmark.md)
   - Spotlight：ConceptGuard 把 unlearning 从 fact-level 推进到 concept-level，使安全语境下的能力验证更贴近线上治理需求。
   - 论文链接：[https://arxiv.org/abs/2608.20338](https://arxiv.org/abs/2608.20338)

2. [02-ai4ai-bench-rsi.md](02-ai4ai-bench-rsi.md)
   - Spotlight：AI4AI-Bench 定义了“改代码改算法”与“真改进”分离的 benchmark，可评测 LLM agent 的递归改进潜力边界。
   - 论文链接：[https://arxiv.org/abs/2608.20318](https://arxiv.org/abs/2608.20318)

3. [03-4danyone.md](03-4danyone.md)
   - Spotlight：4DAnyone 通过 context packing + context routing 解决单目视频到 4DGS 的扩展瓶颈，兼顾生成质量与重建性能。
   - 论文链接：[https://arxiv.org/abs/2608.20335](https://arxiv.org/abs/2608.20335)

4. [04-towards-surgical-world-action-modeling.md](04-towards-surgical-world-action-modeling.md)
   - Spotlight：该工作把视觉状态与器械轨迹联合建模并用 chunked rollout 提升短中期稳定性，对具身手术 AI 的闭环规划很有启发。
   - 论文链接：[https://arxiv.org/abs/2608.20284](https://arxiv.org/abs/2608.20284)

5. [05-bert-ler-ehr-explainable.md](05-bert-ler-ehr-explainable.md)
   - Spotlight：BERT-LER 在结构化 EHR 上把实验室定量建模与 Integrated-Gradients 归因放在同一模型体系，兼顾精度和可解释性。
   - 论文链接：[https://arxiv.org/abs/2608.20315](https://arxiv.org/abs/2608.20315)
