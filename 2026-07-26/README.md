### 当日推荐列表（Spotlight 与链接）
1. **MemTools: A Unified Research Framework for Interoperable Agent Memory**  
   SpotLight：构建可互操作 Agent Memory 标准接口，减少记忆研究中“系统耦合导致的假进步”。  
   链接：<https://arxiv.org/abs/2607.21404>

2. **AXIS: A Growable Community-Driven Data Engine for Scalable Robot Manipulation**  
   SpotLight：结合社区采集、任务生成和统一评测，给出了机器人操纵数据规模增长与策略提升的闭环路径。  
   链接：<https://arxiv.org/abs/2607.21588>  
   项目页：<https://axisaiorg.github.io/AXIS-V1/>

3. **Synthetic data generation framework for quality control automation in gravure printing**  
   SpotLight：用可控合成样本构建工业缺陷数据，直接报告 RFDETR 的真实测试表现。  
   链接：<https://arxiv.org/abs/2607.21577>

4. **Surprisal Theory is Tautological (without Rational Grounding)**  
   SpotLight：从理论可证伪性角度反驳了 Surprisal Theory 的默认解读，提醒 LLM 解释研究警惕“拟合即解释”。  
   链接：<https://arxiv.org/abs/2607.21574>

5. **Scalable Low-Cost Laboratory Automation: A Digital Twin-Integrated Robotic Platform for Autonomous Liquid Handling (RAINBOTTM)**  
   SpotLight：低成本液体处理硬件+数字孪生闭环，突出 AI4S 的可达性与可复制性。  
   链接：<https://arxiv.org/abs/2607.20662>
